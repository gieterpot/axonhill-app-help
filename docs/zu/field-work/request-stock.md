# Cela i-stock

<p class="guide-meta">Kuhlolwe nge-request yokuhlola ngo-20 Agasti 2026.</p>

Sebenzisa **Stock requests** uma indawo yakho idinga into.

1. Vula **Stock**, bese uvula **Stock requests**.
2. Khetha **+** ukuqala i-request.
3. Hlola **Requesting location**. Uma uphethe izindawo ezingaphezu kweyodwa, khetha indawo efanele ngokwakho.
4. Faka i-note emfushane uma izosiza ihhovisi.
5. Ngaphansi kwezinto eziceliwe, khetha **New**.
6. Khetha into, i-brand, usayizi noma imodeli.
7. Faka inani elingaphezu kuka-zero bese ugcina into.
8. Faka enye into uma idingeka.
9. Hlola yonke imigqa bese ukhetha **Save** kanye kuphela.
10. Gcina uhlelo luvulekile luze luqede i-sync.

Ifomu yamanje ingaba banzi ngemva kokufaka into. Uma **Save** ifihlakele kancane, swayipha eceleni ngokucophelela. Ungenzi i-request yesibili ngaphandle kokuthi eyokuqala ayibonakali ngemva kwe-sync ephelele.
