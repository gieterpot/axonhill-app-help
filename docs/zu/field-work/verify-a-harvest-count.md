# Qinisekisa ukubalwa komsebenzi

<p class="guide-meta">Kusalungiswa. Imininingwane eboniswayo ihloliwe. Umphumela ophelele ka-Y no-N usadinga ukuhlolwa.</p>

Umuntu owenze umsebenzi kufanele ahlole ukubalwa ngaphambi kokuthi kugcinwe.

## Hlola yonke imininingwane

Funda umbhalo wokuqinisekisa ocingweni. Hlola:

- i-Chainsaw Operator;
- i-Marker 1;
- i-Marker 2, uma kusebenze ama-marker amabili;
- i-Debarker;
- yonke i-work type;
- lonke inani.

Ungahloli i-total kuphela. Hlola amagama abasebenzi nomugqa ngamunye womsebenzi.

## Uma konke kulungile

1. Khetha **Y**.
2. Vula indawo ye-signature uma ucelwa.
3. Cela umsebenzi oqinisekisayo asayine.
4. Vumela i-counter igcine ukubalwa kanye kuphela.

## Uma kukhona okungalungile

1. Khetha **N**.
2. Ungasayini ukuthi kulungile.
3. Tshela i-counter ukuthi yiliphi igama, i-work type noma inani elingalungile.
4. Lungisa ukubalwa ngaphambi kokuthi kugcinwe ekugcineni.

Ungalokothi ukhethe **Y** ngoba ufuna ukuqeda ifomu kuphela.
