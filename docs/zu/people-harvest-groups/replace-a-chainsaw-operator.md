# Shintsha osebenzisa i-chainsaw ku-Harvest Group

<p class="guide-meta">Kusalungiswa. Uhlu lwabasebenzi luhloliwe, kodwa ifomu yamanje ilahlekelwa yi-Team ne-Harvest Group okuyiwa kuyo.</p>

Sebenzisa lokhu uma umuntu oyedwa eyeka ukuba i-chainsaw operator ye-group, omunye athathe indawo yakhe.

!!! warning "Ungathumeli uma i-Team noma i-Harvest Group inyamalala"
    Ifomu yamanje ingafihla futhi isule i-Team ne-Harvest Group okuyiwa kuyo ngemva kokukhetha **Replace Chainsaw Operator**. Uma okunye kungabonakali, khansela ifomu. I-request engenazo lezi zinkambu ihlala ku-Pending futhi ayimshintshi umuntu.

Umuntu omdala uyasuswa ku-Harvest Group. Sebenzisa ukushintsha umsebenzi okuvamile uma umuntu omdala kufanele ahlale kule group enza omunye umsebenzi.

![I-HR Setup enethayela le-Harvesting Groups](../assets/screenshots/office/choose-app-office-hr-setup.png)

## Izinyathelo

1. Vula i-Office app.
2. Vula **HR Setup**.
3. Vula **Harvesting Groups**.
4. Vula i-group efanele.
5. Khetha **Add Employee**.
6. Ku-**Request Type**, khetha **Replace Chainsaw Operator**.
7. Qinisekisa ukuthi **To this team** ne-**To this harvest group** kusabonisa imininingwane efanele. Uma okunye kunyamalala, khansela uyeke.
8. Ku-**Employee**, khetha i-chainsaw operator entsha.
9. Khetha usuku aqala ngalo.
10. Faka i-note uma idingeka.
11. Khetha **Save** kanye kuphela uma zombili izinkambu zisabonakala.

Uhlu lubonisa abasebenzi abasebenzayo abane-default role ethi **Chainsaw Operator**. Lungabandakanya abantu bakwamanye ama-team, ngakho hlola igama kahle.

## Hlola umphumela

Uma uhlelo seluvumelanisile, vula i-Harvest Group futhi. Hlola ukuthi:

- umuntu omusha uyi-**Chainsaw Operator** yamanje;
- umuntu wangaphambili akaselona ilungu lamanje lale Harvest Group.
