# Hlola ukubalwa okudinga ukunakwa

<p class="guide-meta">Kusalungiswa. Uhlu nemininingwane kuhloliwe. Umphumela we-Override Verification usadinga ukuhlolwa okulawulwayo.</p>

Sebenzisa **Counts Needing Review** ekubalweni okungaqedanga ukuqinisekiswa okuvamile komsebenzi.

## Hlola ukubalwa

1. Vula i-Office app.
2. Khetha **Counts Needing Review**.
3. Thola ukubalwa ngosuku, ngomsebenzi, nge-Team noma nge-Harvest Group.
4. Vula ukubalwa.
5. Hlola i-compartment, i-Team ne-Harvest Group.
6. Hlola osebenzisa i-chainsaw, i-debarker, u-Marker 1 no-Marker 2 lapho beboniswa khona.
7. Hlola zonke izinhlobo zomsebenzi, amanani nama-unit.
8. Funda ama-note ne-status yamanje.

## Nquma okufanele ukwenze

- Uma kukhona imininingwane engalungile noma engacacile, yima ubuze i-counter noma i-supervisor ukuthi iqinisekise.
- Sebenzisa **Override Verification** kuphela uma ugunyaziwe futhi usuqinisekise ukuthi yonke imininingwane ebonisiwe ilungile.
- Ungathumeli okunye ukubalwa ngoba nje okokuqala kusekulolu hlu.

Ngemva kwesenzo esigunyaziwe, vumelanisa bese uqinisekisa ukuthi ukubalwa kuphuma ohlwini lokuhlolwa nokuthi ama-worklog avela kahle.
