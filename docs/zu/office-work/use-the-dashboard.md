# Sebenzisa i-dashboard ye-Office

<p class="guide-meta">Kusalungiswa. Okuqukethwe yi-dashboard kuhloliwe. Izithombe zomphakathi zisadinga idatha yokubonisa.</p>

Sebenzisa i-dashboard ukubona kafushane ama-worklog, i-attendance nama-payroll report.

## Izinyathelo

1. Vula i-Office app.
2. Khetha **Dashboard** kumenyu eseceleni.
3. Linda ama-panel alayishe. Ekuhlolweni kuthathe cishe imizuzwana engu-15.
4. Bheka ama-panel owadingayo:
   - **Worklogs per Team**;
   - **Worklogs per Harvest Group**;
   - **Worklogs Per Compartment**;
   - **Employees Present vs Expected**;
   - **Worklogs This Month**;
   - **Payroll Reports**.
5. Khetha into kuphela uma udinga imininingwane yayo.

## Uma i-dashboard ihlala ingenalutho

1. Linda okungenani imizuzwana engu-20.
2. Khetha **Reset Dashboard** kanye kuphela.
3. Uma ama-panel engaveli, vumelanisa uhlelo bese uzama futhi.
4. Uma namanye ama-view ehamba kancane noma engenalutho, sebenzisa umhlahlandlela othi **Uhlelo aluvuleki noma aluvumelanisi**.
