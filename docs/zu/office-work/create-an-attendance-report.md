# Yenza i-attendance report

<p class="guide-meta">Kusalungiswa. Ifomu le-request nomphumela we-report ekhona kuhloliwe. I-report entsha yokuhlola isadingeka.</p>

Sebenzisa i-attendance report ukuhlola ukuba khona kwansuku zonke phakathi kwezinsuku ezikhethiwe. Ungayikhawulela nge-Team noma nge-Harvest Group.

## Yenza i-report

1. Vula i-Office app.
2. Khetha **Attendance Reports**.
3. Khetha **Add**.
4. Faka usuku lokuqala nosuku lokugcina.
5. Uma ufuna ukuyikhawulela, khetha i-Team noma i-Harvest Group. Kushiye kungenalutho ukuze uthole i-report ebanzi.
6. Faka i-note uma izosiza ukukhomba i-request.
7. Khetha **Save** kanye kuphela.

Uma i-Team ingenalutho, uhlu lwe-Harvest Group lubonisa wonke ama-group asebenzayo kuwo wonke ama-Team.

## Vula umphumela

1. Linda uhlelo luvumelanise futhi i-status ye-report ibe **Generated**.
2. Vula i-record ye-report.
3. Hlola izinsuku nama-filter ayo.
4. Vula imigqa ye-attendance report.
5. Hlola usuku lomsebenzi ngamunye, i-status yosuku, i-Team, i-Harvest Group kanye nemininingwane ye-clock.
6. Sebenzisa **Export CSV** kuphela uma udinga ikhophi ye-spreadsheet.

Uma i-report ingabi **Generated**, ungenzi ama-request aphindaphindiwe. Vumelanisa kuqala, bese ubika i-request ebambekile kumlawuli wohlelo.
