# Uhlelo aluvuleki noma aluvumelanisi

<p class="guide-meta">Umhlahlandlela usalungiswa. Kugcine ukubhekwa ngomhlaka 19 Agasti 2026.</p>

Zama lezi zinyathelo ngokulandelana. Yeka uma uhlelo selusebenza.

## 1. Hlola i-internet

1. Vula enye i-website kuleyo foni noma ikhompyutha.
2. Uma ingavuleki, lungisa i-Wi-Fi noma i-mobile data kuqala.

## 2. Linda i-sync yamanje

Uma uphawu lwe-sync lusahamba, linda umzuzu owodwa. Ungacindezeli i-sync kaningi.

## 3. Vala bese uvula uhlelo

1. Vala uhlelo lwe-AxonHill noma i-browser tab.
2. Luvule futhi.
3. Ngena uma ucelwa.
4. Linda ikhasi lokuqala liqede ukuvula.

## 4. Zama futhi kanye

Khetha i-sync kanye bese ulinda.

## 5. Bika umlayezo ofanele

Uma uhlelo lusahluleka:

1. Thatha isithombe sawo wonke umlayezo.
2. Bhala isikhathi nokuthi usebenzise luphi uhlelo.
3. Bhala ukuthi ubuzama ukwenzani.
4. Thumela lokhu kumphathi wakho noma ku-WhatsApp group efanele.

Uma umlayezo uthi **Unable to fetch app definition** noma **Timed out waiting for a resource**, faka lawo magama njengoba enjalo. Lokhu kusiza umlawuli ahlole ama-table ahamba kancane noma ama-formula ayindilinga.

Ungagcini ukubalwa okufanayo kaningi ngesikhathi uhlelo lumile. Qala uhlole **My Recent Entries** noma **My Recent Batches** uma i-sync isibuyile.
