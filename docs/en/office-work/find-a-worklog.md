# Find a worklog and view its count

<p class="guide-meta">Draft. The list, detail and count-verification link are verified. Public screenshots still need demonstration data.</p>

Use **All Worklogs** to find the work recorded for one employee and trace it back to its count.

## Find the worklog

1. Open the Office app.
2. Select **All Worklogs**.
3. Choose the required date in the left-hand list.
4. Find the employee row.
5. Check the role, Team, Harvest Group, compartment, work type, quantity, unit and status.
6. Open the row to see its detail.

## View the source count

1. In the worklog detail, select **View Count Verification**.
2. Compare the worklog with the employees, work types and quantities in the count.
3. Return to the worklog when finished.

Do not use **Edit** merely to inspect a worklog. The current edit form contains internal fields and is intended for controlled corrections only.
