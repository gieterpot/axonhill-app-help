# Use the Office dashboard

<p class="guide-meta">Draft. The dashboard content is verified. Public screenshots still need demonstration data.</p>

Use the dashboard for a quick overview of current worklogs, attendance and payroll reports.

## Steps

1. Open the Office app.
2. Select **Dashboard** from the side menu.
3. Wait for the panels to load. In testing, this took about 15 seconds.
4. Review the panels you need:
   - **Worklogs per Team**;
   - **Worklogs per Harvest Group**;
   - **Worklogs Per Compartment**;
   - **Employees Present vs Expected**;
   - **Worklogs This Month**;
   - **Payroll Reports**.
5. Select an item only when you need its underlying detail.

## If the dashboard stays blank

1. Wait at least 20 seconds.
2. Select **Reset Dashboard** once.
3. If the panels still do not appear, sync the app and try again.
4. If other views are also slow or blank, use the **App will not open or sync** guide.
