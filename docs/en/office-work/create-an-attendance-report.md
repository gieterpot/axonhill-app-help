# Create an attendance report

<p class="guide-meta">Draft. The request form and existing report result are verified. A new controlled report still needs testing.</p>

Use an attendance report to review daily attendance for a date range, with optional Team or Harvest Group filtering.

## Create the report

1. Open the Office app.
2. Select **Attendance Reports**.
3. Select **Add**.
4. Enter the start date and end date.
5. To limit the report, choose a Team or Harvest Group. Leave them blank for a wider report.
6. Add a note if it will help identify the request.
7. Select **Save** once.

If Team is blank, the Harvest Group list shows active groups from all teams.

## Open the result

1. Wait for the app to sync and the report status to become **Generated**.
2. Open the report record.
3. Check its date range and filters.
4. Open the attendance report lines.
5. Review each employee's date, daily status, Team, Harvest Group and clock information.
6. Use **Export CSV** only when you need a spreadsheet copy.

If the report does not become **Generated**, do not create duplicates. Sync first, then report the stuck request to the administrator.
