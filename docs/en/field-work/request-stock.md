# Request stock

<p class="guide-meta">Checked with a controlled test request on 20 August 2026.</p>

Use **Stock requests** when your location needs an item.

1. Open **Stock**, then **Stock requests**.
2. Select **+** to start a request.
3. Check **Requesting location**. If you control more than one location, choose the correct one yourself.
4. Add a short note when it will help the Office.
5. Under requested items, select **New**.
6. Choose the item, brand, size or model.
7. Enter a quantity greater than zero and save the item.
8. Add another requested item if needed.
9. Check every line and select **Save** once.
10. Keep the app open until it finishes syncing.

The current form can become wider after an item is added. If **Save** is partly hidden, swipe sideways carefully. Do not create a second request unless the first one is definitely absent after a complete sync.
