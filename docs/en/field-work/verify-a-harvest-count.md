# Verify a harvest count

<p class="guide-meta">Draft. The verification details are confirmed in the app. The complete Yes and No outcomes still need controlled tests.</p>

The person who did the work must check the count before it is saved.

## Check every detail

Read the verification text on the phone. Check:

- Chainsaw Operator;
- Marker 1;
- Marker 2, if a second marker worked;
- Debarker;
- every work type;
- every quantity.

Do not check only the total. Check the employee names and each work line.

## If everything is correct

1. Select **Y**.
2. Unlock the signature box when asked.
3. Ask the verifying employee to sign.
4. Let the counter save the count once.

## If anything is wrong

1. Select **N**.
2. Do not sign the form as correct.
3. Tell the counter which name, work type or quantity is wrong.
4. Correct the count before it is finally saved.

Never select **Y** just to finish the form.
