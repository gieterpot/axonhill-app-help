# View current Harvest Group members

<p class="guide-meta">Verified with an isolated test Harvest Group on 19 August 2026.</p>

Use this when you need the people who are currently assigned to a Harvest Group. Old assignments are excluded.

## Steps

1. Open the Office app.
2. Open **HR Setup**.
3. Open **Harvesting Groups**.
4. Open the required Harvest Group.
5. Select **Current members**.
6. Check the employee and role under each role heading.

![Current members for a demonstration Harvest Group](../assets/screenshots/office/hg-current-members.png)

## If a member is missing

Check that the assignment is active and that its start date has arrived. If the person should be in the group now, use the correct assignment request instead of editing an old history row.

Use **Full membership history** when you need to see old or ended assignments.
