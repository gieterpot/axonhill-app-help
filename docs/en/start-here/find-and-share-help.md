# Find and share help

<p class="guide-meta">Draft. The controls are built, but final Android browser testing is still required.</p>

Each guide explains one task. You do not need to read the whole help site.

## Find a guide

1. Open **AxonHill App Help**.
2. Select the search sign.
3. Type a short word, such as `count`, `attendance`, `HG`, `employee` or `sync`.
4. Open the guide that matches your task.

You can also open a section from the menu.

## Change the language

At the top of a guide, select **Funda ngesiZulu** to open the same guide in isiZulu.

On an isiZulu guide, select **Funda nge-English** to return to English.

## Share a guide

At the top of the guide, choose one option:

- **Share** opens the phone's normal share menu, when the browser supports it.
- **Share on WhatsApp** opens WhatsApp with the guide title and link.
- **Copy link** copies the guide address so you can paste it into a message.

Check the message before sending it.

## Download a guide for offline use

Approved count and attendance guides show **Download for offline use** at the top.

1. Select **Download for offline use**.
2. Send the downloaded HTML file through WhatsApp, or keep it on the phone.
3. Open the file in a browser when there is no signal.

The offline file is a saved copy. Use the online guide again when you have a connection so that you see the latest instructions.
